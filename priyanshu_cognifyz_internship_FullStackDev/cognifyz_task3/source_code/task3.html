FAQ

Common questions

What CSS features are covered?
We cover CSS custom properties (variables), transitions, keyframe animations, transforms, grid, flexbox, filters, backdrop-blur, clip-path, and more — all with real production examples.
Is Bootstrap 5 required?
No. Bootstrap 5 is optional and layered on top. All core layouts and custom CSS work standalone. Bootstrap simply accelerates the grid and component layer.
How is responsiveness handled?
We use a mobile-first approach: base styles target small screens, then Bootstrap breakpoints (sm, md, lg, xl, xxl) and custom media queries extend the layout for larger viewports.
Can I use this commercially?
Absolutely. Pro and Agency plans include full commercial usage rights and white-label export options for client projects.
Do animations affect performance?
All animations use GPU-composited properties — transform and opacity — to avoid layout thrashing. We also include prefers-reduced-motion support out of the box.
