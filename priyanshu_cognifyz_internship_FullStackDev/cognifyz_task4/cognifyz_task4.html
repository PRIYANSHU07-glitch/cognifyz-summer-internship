    About This Project

    This project is the Level 2, Task 4 submission for Cognifyz Technologies — demonstrating complex form validation, real-time DOM manipulation, and client-side routing in a pure HTML/CSS/JS Single Page Application.

    What's implemented:

    Password Strength Meter Multi-Step Validation Hash-based SPA Routing Dynamic Tag Input Live Todo List Real-time Color Preview Browser History API Regex Validation Zero Dependencies

    Built with Vanilla JS · CSS Custom Properties · Google Fonts
    No frameworks, no libraries — just the web platform.
