# Task 1 - HTML Structure and Basic Server Interaction

## Objective
The objective of this task was to understand the basics of server-side rendering and form handling using Node.js and Express.

## Features
- Created HTML forms for user input
- Built a basic Node.js server using Express
- Implemented server-side endpoints for form submission
- Used EJS for dynamic HTML rendering

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EJS

## Outcome
This task helped in understanding the fundamentals of server-client interaction and server-side rendering.
